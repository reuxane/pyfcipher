# pyfcipher

Простой консольный инструмент для шифрования и дешифрования файлов по паролю.
Исходный файл не изменяется: результат сохраняется рядом отдельным файлом.

## Возможности

- Шифрование и дешифрование любого файла по паролю
- Ключ выводится из пароля через PBKDF2-HMAC-SHA256 (600 000 итераций)
- Случайная соль для каждого файла
- Шифрование Fernet (AES + HMAC): данные защищены и от подмены
- Файлы не перезаписываются: при совпадении имени добавляется `.1`, `.2` и т. д.
- Пароль вводится скрытно (`getpass`)

## Установка

```bash
python -m pip install cryptography
```

Нужен Python 3.8+.

## Использование

```bash
python hifr.py
```

1. Выберите действие: `1` — шифровать, `2` — дешифровать
2. Введите путь к файлу
3. Введите пароль (при шифровании — дважды)

| Действие | Было | Стало |
|---|---|---|
| Шифрование | `photo.jpg` | `photo.jpg.enc` |
| Дешифрование | `photo.jpg.enc` | `photo.jpg` |

## Как это работает

Файл `.enc` имеет формат: `FCIPHER1` (метка) + 16 байт соли + токен Fernet.

## Важно

- **Если забудете пароль, восстановить данные невозможно.**
- Файл целиком загружается в память, поэтому для очень больших файлов инструмент не подходит.
- Проект учебный.
